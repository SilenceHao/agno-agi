# 本地智能体

基于 Agno、FastAPI 和 DeepSeek 的通用智能体，可在 Windows 原生 Python 环境运行，不需要 Docker。支持通用对话、SSE 流式回答、Markdown 排版、临时聊天附件，以及独立维护的本地知识库。

## 环境要求

- Python 3.11 或更高版本
- DeepSeek API Key
- 能访问 DeepSeek API 的网络
- Ollama 与本机 `bge-m3` 向量模型（知识库索引功能）

## Windows 启动

在 PowerShell 中进入项目目录后执行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

把 `.env` 中的 `DEEPSEEK_API_KEY` 替换成自己的密钥，然后启动：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

也可以直接运行项目根目录的 `start.ps1`。它会固定使用 `.venv\Scripts\python.exe`，避免调用系统全局 Python 导致知识库依赖（LanceDB）缺失。若 PowerShell 禁止脚本执行，可使用下面的等价命令：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。首次使用先注册账号，之后登录进入工作区。账号不区分大小写且不可重复，密码需为 8 到 128 个字符。账号 `16602024093` 在本机首次注册后会成为超级管理员；建议先用本机地址完成该账号注册，再开放局域网访问。超级管理员可从左下角账号菜单进入独立的智能体管理工作台，维护知识库和 HTTP 工具；普通账号使用对话端并只能查看自己的对话记录。管理工作台沿用同一登录会话，管理页面和资源 API 均要求超级管理员权限。登录状态保存在 HttpOnly Cookie 中，退出登录或会话过期后需要重新登录。API 文档可在 <http://127.0.0.1:8000/docs> 查看。

首次安装依赖需要网络。服务默认仅监听本机回环地址；如果之后要让局域网其他设备访问，可将 host 改为 `0.0.0.0`，并配置防火墙与访问认证。

## 使用说明

可以直接输入任意问题，也可以在对话框上传临时附件。支持 PDF、DOCX、TXT、Markdown，以及 JPEG、PNG、WebP 图片；单个文件最大 10 MB，每次最多 5 个附件。输入框的“深度思考”开关控制本轮 DeepSeek 请求是否启用思考模式；开启后，模型返回的思考内容会在独立面板中流式显示，最终回答仍显示在单独的回答区域。思考内容只显示在当前页面，不保存到对话历史。图片会使用项目环境配置中的 DEEPSEEK_VISION_MODEL 发送给 DeepSeek API，不会保存图片原始字节；刷新或后续提问如需再次分析图片，需要重新上传。视觉模型默认值为方案中的 deepseek-v4-flash-vision-exp，请确认你的 DeepSeek API 账号支持该模型后再验证。临时附件不会写入长期知识库。

超级管理员从左下角账号菜单打开 **管理工作台**，在独立管理页面中切换知识库、工具和工作流管理。知识库页面可上传、查看索引状态、重新索引和删除资料；工具管理用于配置固定 HTTP 接口：填写工具英文标识、用途说明、请求方式、URL、参数位置（路径、查询参数或 JSON 请求体）和固定请求头后，启用的工具会注册给 Agno；智能体会在问题匹配时提取参数并调用接口。请求头中的鉴权值只保存在本机 SQLite，不会返回到网页。页面提供真实连接测试，测试会向配置的地址发起请求。普通调用不再做字符级响应裁剪，但 HTTP 响应读取上限仍为 4 MB；模型上下文容量有限，大量列表仍建议配置接口分页。

在 **管理工作台 → 工作流管理** 中，超级管理员可以创建顺序工作流，添加智能体、知识库和 HTTP 工具节点，保存草稿并发布。节点可用 `{{input}}` 引用用户输入、`{{previous}}` 引用上一步输出。管理页可以预览草稿，预览仅超级管理员可用且不会写入会话记录；HTTP 节点会真实调用配置接口，写请求可能修改外部数据。发布后，登录用户可在聊天输入框选择工作流运行，问题和最终结果会保存在当前会话。工作流节点的知识库目录和 HTTP 工具仍受运行用户当前授权限制。当前支持顺序执行，尚未提供条件分支、并行节点、版本回滚和执行审计。

在 **管理工作台 → 模型与提示词** 中，超级管理员可维护普通对话模型、视觉模型、DeepSeek 兼容 API 地址和全局补充提示词。配置保存于本机 SQLite，模型设置立即用于后续对话、视觉资料处理和工作流智能体节点；API Key 只写入服务端，不会读回网页。连接测试只请求 `/models` 接口，不会生成回答或消耗模型输出 Token。原有 `.env` 值作为未配置数据库覆盖项时的默认值；全局补充提示词会与内置安全指令一并发送，内置指令保持在补充提示词之后。

在 **管理工作台 → 知识库管理** 中先创建或选择目录，再导入资料。目录首页按目录名称搜索和分页；进入目录后按文件名搜索、分页和上传。支持导入 Excel 工作簿（XLS、XLSX、XLSM），索引内容包含工作表名称、行号、表头字段名和单元格值；已有 Excel 文件需重新索引或重新导入以加入表头字段。原始文件保存在 `KNOWLEDGE_DATA_DIR/files`，使用 Ollama `bge-m3` 在本机向量化，索引默认保存在项目的 `data/knowledge/vectors`；可在 `.env` 中设置 `KNOWLEDGE_VECTOR_DIR` 修改向量索引位置。普通用户的检索始终在检索前限定到角色已授权目录，并在返回前再次校验当前权限。检索使用向量和全文关键词混合召回及 RRF 排序，短指代问题会结合近期用户问题补全实体，字段意图会扩展价格、联系方式、地址、时间和规格等表达；首轮命中不足时自动进行放宽阈值的二次检索。超级管理员可以检索全部目录。聊天输入框的“检索知识库”默认开启；关闭后本轮不检索长期资料。回答问题时只把检索到的相关片段发送给 DeepSeek。可在管理工作台查看索引状态、重新索引或删除文件。

知识库目录功能首次启用时会清理旧知识库测试资料、原始文件和向量索引，并创建默认的“未分类”目录；用户、对话记录和 HTTP 工具配置会保留。升级后首次启动服务时会执行这次清理，之后新导入的资料需要放入对应目录。

知识库支持 PDF、DOCX、TXT、Markdown、JPEG、PNG、WebP，以及 MP4、MOV、MKV、WebM、AVI；单个文件最大 100 MB，文本最多 5,000,000 字符。独立图片、PDF/Word 内嵌图片和视频关键帧通过 DeepSeek 视觉模型生成可检索描述，PDF/Word 文档最多处理 50 张内嵌图片；Word 文档搜索图片问题时会提供站内原图预览。升级图片检索逻辑后，需在知识库页对已有 Word/PDF 文档点击“重新索引”，让每张内嵌图片分别建立检索单元。原始文件与向量索引仍保存在本机。视频最多抽取 8 个关键帧，搜索描述带时间戳；当前不转写音轨，需在系统 PATH 中安装 FFmpeg/FFprobe。扫描版 PDF 暂不支持 OCR。默认数据路径为 `D:/AI-Agent/knowledge`，可在 `.env` 中通过 `KNOWLEDGE_DATA_DIR` 修改。Ollama 默认地址为 `http://127.0.0.1:11434`，模型默认 `bge-m3`、向量维度 1024。

对话、消息和附件提取文本保存在项目的 `data/agent.db` SQLite 数据库中。刷新页面会自动恢复最近一条对话；左侧列表可以切换或删除记录。原始附件文件不会保存。需要清空所有本地记录时，先停止服务，再删除 `data/agent.db`。

## 隐私与配置

服务运行在本机，但发送给模型的对话文本、附件提取文本和本轮图片会传至 DeepSeek API；本机 SQLite 会保存对话文本、附件名称和附件提取文本，不保存图片原始字节。不要上传不适合发送给第三方模型服务的内容。API Key 只放在 `.env` 文件中，不要提交到 Git。

默认模型为 `deepseek-chat`。`.env` 中的 `DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL` 和 `DEEPSEEK_VISION_MODEL` 用作管理工作台尚未保存对应设置时的默认值。
