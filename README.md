# 本地智能体

基于 Agno 和 FastAPI 的多智能体工作区，可在 Windows 原生 Python 环境运行，不需要 Docker。支持按智能体配置 DeepSeek 或 OpenAI 兼容模型、SSE 流式回答、临时聊天附件，以及独立维护的本地知识库。

## 环境要求

- Python 3.11 或更高版本
- 至少一个可用的大模型 API Key
- 能访问所选模型服务的网络
- Ollama 与本机 `bge-m3` 向量模型（知识库索引功能）

## Windows 启动

在 PowerShell 中进入项目目录后执行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

启动服务后，使用超级管理员进入管理工作台，在“智能体列表”中新增智能体并配置模型供应商、模型、Base URL 和 API Key。API Key 会按智能体加密保存在本机 SQLite 中，浏览器不会读取密钥明文。

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

也可以直接运行项目根目录的 `start.ps1`。它会固定使用 `.venv\Scripts\python.exe`，避免调用系统全局 Python 导致知识库依赖（LanceDB）缺失。若 PowerShell 禁止脚本执行，可使用下面的等价命令：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。首次使用先注册账号，之后登录进入工作区。账号不区分大小写且不可重复，密码需为 8 到 128 个字符。账号 `16602024093` 在本机首次注册后会成为超级管理员；建议先用本机地址完成该账号注册，再开放局域网访问。超级管理员可从左下角账号菜单进入独立的智能体管理工作台，维护知识库和 HTTP 工具；普通账号使用对话端并只能查看自己的对话记录。管理工作台沿用同一登录会话，管理页面和资源 API 均要求超级管理员权限。登录状态保存在 HttpOnly Cookie 中，退出登录或会话过期后需要重新登录。API 文档可在 <http://127.0.0.1:8000/docs> 查看。

首次安装依赖需要网络。服务默认仅监听本机回环地址；如果之后要让局域网其他设备访问，可将 host 改为 `0.0.0.0`，并配置防火墙与访问认证。

## 使用说明

可以直接输入任意问题，也可以在对话框上传临时附件。支持 PDF、DOCX、TXT、Markdown，以及 JPEG、PNG、WebP 图片；单个文件最大 10 MB，每次最多 5 个附件。输入框的“深度思考”开关控制当前智能体是否启用对应模型的思考模式；图片使用当前智能体配置的视觉模型处理。临时附件不会写入长期知识库。

超级管理员从左下角账号菜单打开 **管理工作台**，在独立管理页面中切换知识库、工具和工作流管理。知识库页面可上传、查看索引状态、重新索引和删除资料；工具管理用于配置固定 HTTP 接口：填写工具英文标识、用途说明、请求方式、URL、参数位置（路径、查询参数或 JSON 请求体）和固定请求头后，启用的工具会注册给 Agno；智能体会在问题匹配时提取参数并调用接口。请求头中的鉴权值只保存在本机 SQLite，不会返回到网页。页面提供真实连接测试，测试会向配置的地址发起请求。普通调用不再做字符级响应裁剪，但 HTTP 响应读取上限仍为 4 MB；模型上下文容量有限，大量列表仍建议配置接口分页。

在 **管理工作台 → 工作流管理** 中，超级管理员可以创建顺序工作流，添加智能体、知识库和 HTTP 工具节点，保存草稿并发布。节点可用 `{{input}}` 引用用户输入、`{{previous}}` 引用上一步输出。管理页可以预览草稿，预览仅超级管理员可用且不会写入会话记录；HTTP 节点会真实调用配置接口，写请求可能修改外部数据。发布后，登录用户可在聊天输入框选择工作流运行，问题和最终结果会保存在当前会话。工作流节点的知识库目录和 HTTP 工具仍受运行用户当前授权限制。当前支持顺序执行，尚未提供条件分支、并行节点、版本回滚和执行审计。

在 **管理工作台 → 智能体列表** 中，超级管理员可新增并维护多个独立智能体。每个智能体拥有独立的模型供应商、普通模型、视觉模型、Base URL、API Key、提示词、会话、知识库、HTTP 工具和工作流。只有已发布且配置了 API Key 的智能体会出现在普通用户的对话端。全局模型配置入口已取消，模型设置立即用于后续对话、视觉资料处理和工作流节点。

在 **管理工作台 → 知识库管理** 中先创建或选择目录，再导入资料。目录首页按目录名称搜索和分页；进入目录后按文件名搜索、分页和上传。支持导入 Excel 工作簿（XLS、XLSX、XLSM），索引内容包含工作表名称、行号、表头字段名和单元格值；已有 Excel 文件需重新索引或重新导入以加入表头字段。原始文件保存在 `KNOWLEDGE_DATA_DIR/files`，使用 Ollama `bge-m3` 在本机向量化，索引默认保存在项目的 `data/knowledge/vectors`；可在 `.env` 中设置 `KNOWLEDGE_VECTOR_DIR` 修改向量索引位置。普通用户的检索始终在检索前限定到角色已授权目录，并在返回前再次校验当前权限。检索使用向量和全文关键词混合召回及 RRF 排序，短指代问题会结合近期用户问题补全实体，字段意图会扩展价格、联系方式、地址、时间和规格等表达；首轮命中不足时自动进行放宽阈值的二次检索。超级管理员可以检索全部目录。聊天输入框的“检索知识库”默认开启；关闭后本轮不检索长期资料。回答问题时只把检索到的相关片段发送给当前智能体配置的模型服务。可在管理工作台查看索引状态、重新索引或删除文件。

多智能体版本按全新测试数据初始化。检测到旧版单智能体数据库时，服务会清理旧测试数据并创建新的智能体数据结构，不执行旧数据迁移。每个新智能体都会创建独立的默认“未分类”目录。

知识库支持 PDF、DOCX、TXT、Markdown、JPEG、PNG、WebP，以及 MP4、MOV、MKV、WebM、AVI；单个文件最大 100 MB，文本最多 5,000,000 字符。独立图片、PDF/Word 内嵌图片和视频关键帧通过当前智能体配置的视觉模型生成可检索描述，PDF/Word 文档最多处理 50 张内嵌图片；Word 文档搜索图片问题时会提供站内原图预览。升级图片检索逻辑后，需在知识库页对已有 Word/PDF 文档点击“重新索引”，让每张内嵌图片分别建立检索单元。原始文件与向量索引仍保存在本机。视频最多抽取 8 个关键帧，搜索描述带时间戳；当前不转写音轨，需在系统 PATH 中安装 FFmpeg/FFprobe。扫描版 PDF 暂不支持 OCR。默认数据路径为 `D:/AI-Agent/knowledge`，可在 `.env` 中通过 `KNOWLEDGE_DATA_DIR` 修改。Ollama 默认地址为 `http://127.0.0.1:11434`，模型默认 `bge-m3`、向量维度 1024。

对话、消息和附件提取文本保存在项目的 `data/agent.db` SQLite 数据库中。刷新页面会自动恢复最近一条对话；左侧列表可以切换或删除记录。原始附件文件不会保存。需要清空所有本地记录时，先停止服务，再删除 `data/agent.db`。

## 隐私与配置

服务运行在本机，但发送给模型的对话文本、附件提取文本和本轮图片会传至对应智能体配置的模型服务；本机 SQLite 会保存对话文本、附件名称和附件提取文本，不保存图片原始字节。不要上传不适合发送给第三方模型服务的内容。API Key 加密保存在 `data/agent.db`，加密密钥默认位于 `data/.agent-config.key`，这两个路径均不会提交到 Git。也可以通过 `.env` 中的 `AGENT_CONFIG_ENCRYPTION_KEY` 指定加密密钥。
